Layers of programming

Application

Applications are built to perform particular tasks for the user, they are mostly built with high-level programming languages such as javascript, python and c#. They have the highest level of abstraction and are built to be accessible to people with little to no knowledge of programing.

High-Level Programming Languages

High-Level Programming Languages are used for writing programs or software and can be understood by humans, they use a lot of symbols and logic which humans can understand. It has a high level of abstraction compared to low-level languages and have a lot of usefull characteristics such as automatic memory management meaning you dont have to allocate or free up memory manually, and rich standard librarys which help eliminate having to write common tasks from scratch. High-Level Programming Languages are executed in 3 different ways:

INTERPRETED

Interpreted languages are read and executed directly without a compilation stage; this is because they include a program called an interpreter. The interpreter reads each line of the program, converts it to machine code, executes it, then deletes the machine code.

COMPILED LANGUAGES

Compiled languages are turned into a executable form before running, there are two types of compilation: Machine Code compilation - Some compilers convert written code directly into machine code
